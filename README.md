# Harvest Moon DS – Wichtel-Checkliste

Eine Webseite zum Abhaken aller 101 Wichtel (Harvest Sprites) aus **Harvest Moon DS** (in Europa von Rising Star Games). Die Bedingungen gelten auch für **Harvest Moon DS Cute**.

- Alle 101 Wichtel, sortiert nach den 10 Team-Farben (Braun, Schwarz, Blau, Rot, Gelb, Grün, Indigo, Orange, Lila, Weiß)
- Zu jedem Wichtel: wie du ihn befreist, dazu Tipps
- Abhaken per Klick, Filter nach Team und Status (offen/gefunden), Suche
- Fortschritt mit den Meilensteinen 20 (Earth), 60 (Erntegöttin) und 101
- Speichert automatisch im Browser, dazu ein Sicherungscode zum Übertragen auf andere Geräte

## Benutzen

Einfach `index.html` im Browser öffnen. Es wird nichts installiert.

Als eigene Webseite über GitHub Pages: im Repository unter **Settings → Pages** den Branch mit der `index.html` auswählen und speichern.
